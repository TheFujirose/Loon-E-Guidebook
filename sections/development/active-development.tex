\subsection{Active Development}
\label{sec:active-development}

There are three main areas of active development for the software team: 

\begin{enumerate}
    \item Primary Computer Development
    \item Base Station Development
    \item Web Client Application Development
\end{enumerate}

Each area has its own set of tasks and responsibilities, but they all work together to create a cohesive software system for the Loon-E ASV.

\warningbox{
    Ensure you have the \hyperref[sec:env-vars-setup]{environment variables} set up correctly when developing.
    Check your `~/.bashrc` file for the necessary environment variables and their values.
}

\subsubsection{Primary Computer Development}
This area focuses on the development of the software that runs on the ASV's primary computer, which is responsible for controlling the ASV and processing data from its sensors \autocite{LOONENV}.

To develop you require section \ref{sec:loon-env} which specifies the Loon-Env development environment, which is a Docker-based environment that provides all the necessary tools and dependencies for developing software for the Loon-E ASV.
