# LaTex-Template
A LaTex Template for professional documentation regarding Humber ASV for project team reading, stakeholders, and other parties.

## Installation

This is a document, so no installation is required. However, you will need a LaTex distribution to compile the document.

> [!NOTE]
>
> This template is designed to be used with [Tex Live](https://tug.org/texlive/) Any LaTex distribution should work, but Tex Live is recommended for best compatibility.

---
## Usage

To use this template, simply clone the repository and open the `main.tex` file in your LaTex editor. You can then edit the content as needed.

You need to compile the `main.tex` file to generate the PDF document. The template is set up to use `pdflatex`, but you can use any LaTex compiler that you prefer. You will also need to use `bibtex` to compile the bibliography if you have citations.

```bash
LaTex-Template
├───citations/       # Citation files (BibTeX format)
├───code/            # Code snippets and examples
├───images/          # Images used in the document
├───sections/        # Sections of the document
├───main.tex         # Main document file
└───preamble.sty     # Preamble file
```
